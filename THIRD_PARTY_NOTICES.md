# Third-party software

SmartIPTV TV uses Kotlin (Apache-2.0), AndroidX Core, RecyclerView and
Media3 (Apache-2.0), OkHttp (Apache-2.0) and their transitive dependencies.
Android framework components are provided by the device operating system.

The application includes no IPTV playlist, provider account, media catalog
or copyrighted video. The synthetic media fixture belongs only to the test APK.
